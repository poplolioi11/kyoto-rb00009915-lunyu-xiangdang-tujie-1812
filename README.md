## 資料與限制

`book.json`保存幀、面、欄、文字層、原字串、疑字、候選與缺口；`book.txt`逐行以`[單位ID]`、TAB及字串呈現；`book.tei.xml`為TEI P5，每幀`pb`、每單位`ab`。原字串不作NFC、簡繁或異體正規化，不加現代句讀，不從記憶或現代平台文字補字。**原有小圈點以「○」依原位記錄，屬原符號的Unicode表記，不是整理者新增標點；字位計數包含這些圈點。**

一字不可辨以「□」及相應疑字記錄表示，TEI編為quantity=1。未知字數另存JSON gap；TXT及TEI追加的`⟦gap:unknown⟧`只報告本單位存在該缺口，**不表示一字，也不表示缺口在行尾**。其理由與可核位置保存於JSON。bbox如有值，為實際2000×1335固定影像的xyxy區域框；空值不表示已定位。圖內文字、原註、訂改及印記各按資料層記錄；JSON細節不被冒稱完整TEI校勘apparatus。

原書後加的現代作者說明、館藏標籤、色卡與可辨紙背透字不併入古籍正文。其排除位置見各頁說明。不打包館藏影像，不複製現代點校、翻譯或目錄解說。有限定向檢索未識別既有OCR、翻刻或整理成果；這不能證明全球不存在，亦不宣稱首次數位化。

本標籤保留初次完整影像讀字狀態；獨立複核完成後另發新版，不覆寫本標籤。
